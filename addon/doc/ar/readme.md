# إضافة Tymer لقارئ الشاشة NVDA

إضافة برمجية متخصصة لإدارة المؤقتات التنازلية عبر قارئ الشاشة NVDA، تتيح للمستخدم تشغيل خمسة مؤقتات مستقلة عبر طبقة أوامر أحادية الاستخدام (One-Shot Modal Command Layer)، مع تنبيهات صوتية ونطقية متقدمة وتوافق تام مع معايير الوصولية.

---

## المزايا والخصائص الأساسية

1. **طبقة أوامر أحادية الاستخدام**: تُفتح بالضغط على الاختصار المخصص `NVDA+Y`، وتُغلق تلقائياً فور تنفيذ الأمر، مما يحمي لوحة المفاتيح من الحبس.
2. **خمسة مؤقتات مستقلة**: مدد افتراضية متدرجة (5، 10، 15، 25، 60 دقيقة).
3. **المؤقت السريع المخصص لمرة واحدة (`Q`)**: فتحة مستقلة في الذاكرة الحية لضبط مؤقت عابر لمرة واحدة دون المساس بالمؤقتات الخمسة الدائمة، تبدأ فور تأكيد نافذة الضبط السريعة الموجهة للدقائق مباشرة.
4. **توزيع متوازن ومحكم للمفاتيح المساعدة**:
   - الأرقام من `1` إلى `5` مجردة: الاستعلام عن الوقت المتبقي، أو بدء العد التنازلي إن كان المؤقت متوقفاً.
   - المفاتيح مع `Shift`: إيقاف المؤقت مؤقتاً أو استئناف العد.
   - المفاتيح مع `Control`: فتح نافذة ضبط المدة (ساعات، دقائق، ثوانٍ) وتسمية المؤقت اختيارياً.
   - المفاتيح مع `Alt`: إعادة ضبط المؤقت إلى مدته الابتدائية وإسكات الرنين.
5. **إجراءات المؤقت السريع (`Q`)**:
   - `Q`: الاستعلام عن الوقت المتبقي (أو فتح حوار الضبط السريع والبدء فوراً إن كان متوقفاً).
   - `Shift+Q`: تعليق المؤقت السريع أو استئنافه.
   - `Control+Q`: فتح حوار ضبط مدة المؤقت السريع في أي وقت والبدء فوراً عند الموافقة.
   - `Alt+Q`: تصفير المؤقت السريع وإيقافه وإسكات رنين التنبيه.
6. **ساعة الإيقاف الخفيفة (`S`)**: قياس الوقت المنقضي تصاعدياً بدقة مع مفاتيح `S` و `Shift+S` و `Control+S` و `Alt+S`.
7. **أوامر مساعدة في الطبقة**:
   - `مسافة (Space)`: إسكات صوت التنبيه فوراً.
   - `A`: الاستماع لتقرير موجز يجمع حالة المؤقتات النشطة.
   - `H`: عرض قائمة الأوامر والمساعدة في نمط التصفح.
   - `هروب (Escape)`: الخروج من الطبقة بهدوء دون فعل أي شيء.
8. **تنبيهات صوتية ونطقية رصينة**:
   - رنين مخصص بصيغة wave ينطلق فور انتهاء العد، ويصمت تلقائياً بعد ثانية واحدة (أو بالضغط على مفتاح المسافة Space داخل الطبقة).
   - مقاطعة الأسبق بالأحدث: حلول أجل أي مؤقت جديد يقطع رنين المؤقت السابق بلا تأخير.
   - نغمة تحذيرية اختيارية قبل بلوغ الصفر بعشر ثوانٍ.
   - مستويان للإسهاب النطقي: للمبتدئين (إرشادات مفصلة) وللمتقدمين (اقتضاب واكتفاء بالأرقام).
9. **حفظ الحالة واستئناف الجلسات**: حفظ المؤقتات النشطة عبر إعادة تشغيل NVDA وفق التفضيل المختار.
10. **لوحة إعدادات مدمجة**: متكاملة بصورة أصيلة ضمن حوار إعدادات NVDA.

## جدول مفاتيح وأوامر الطبقة

افتح الطبقة بالضغط على **`NVDA+Y`**، ثم اضغط المفتاح المطلوب:

| المفتاح | الإجراء |
| :--- | :--- |
| `1` إلى `5` | الاستعلام عن الوقت المتبقي أو بدء المؤقت |
| `Shift` + `1` إلى `5` | إيقاف المؤقت مؤقتاً / استئناف العد التنازلي |
| `Control` + `1` إلى `5` | فتح نافذة تعيين مدة المؤقت والتسمية |
| `Alt` + `1` إلى `5` | إعادة المؤقت إلى مدته الأصلية وتصفيره |
| `Q` | الاستعلام عن المؤقت السريع (أو فتح حوار الضبط والبدء فوراً إن كان متوقفاً) |
| `Shift` + `Q` | تعليق المؤقت السريع مؤقتاً / استئناف العد التنازلي |
| `Control` + `Q` | فتح حوار ضبط مدة المؤقت السريع والبدء فوراً |
| `Alt` + `Q` | تصفير المؤقت السريع وإلغاؤه وإسكات الرنين |
| `S` | الاستعلام عن الوقت المنقضي لساعة الإيقاف، أو بدء تشغيلها |
| `Shift` + `S` | تعليق ساعة الإيقاف / استئناف العد التصاعدي |
| `Control` + `S` | تصفير ساعة الإيقاف وإعادة بدئها فوراً من الصفر |
| `Alt` + `S` | تصفير ساعة الإيقاف وإيقافها عند الصفر |
| `مسافة (Space)` | إسكات صوت الرنين الحالي |
| `A` | تقرير شامل عن كافة المؤقتات النشطة |
| `H` | فتح دليل المساعدة السريع |
| `هروب (Escape)` | إغلاق الطبقة دون تنفيذ أي إجراء |

*تنبيه: ضغط أي مفتاح غير معرف داخل الطبقة يُصدر نغمة خطأ منخفضة ويُغلق الطبقة فوراً حمايةً للمدخلات.*

## إعدادات الإضافة

لتخصيص الخيارات، انتقل إلى: **قائمة NVDA -> تفضيلات -> إعدادات -> Tymer**:

- **نمط الإشعار عند انتهاء المؤقت**: صوت فقط، نطق فقط، صوت ونطق معاً.
- **مستوى الإسهاب النطقي**: مبتدئ (توجيهات مفصلة)، متقدم (أرقام مقتضبة).
- **إصدار نغمة عند الدخول في طبقة الأوامر**: تفعيل أو تعطيل نغمة الدخول عند ضغط `NVDA+Y`.
- **إصدار نغمة تنبيه قبل انتهاء المؤقت بـ 10 ثوانٍ**: تشغيل صفير تنبيهي مبكر.
- **السلوك عند إعادة تشغيل NVDA**: استئناف المؤقتات النشطة، إيقافها جميعاً، أو إبقاؤها موقوفة مؤقتاً.
- **استعادة المدد الأصلية للمؤقتات**: إعادة تعيين المؤقتات الخمسة إلى مدد المصنع (5، 10، 15، 25، 60 دقيقة) وحذف التسميات.
