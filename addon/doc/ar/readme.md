# إضافة المؤقت الفوري (Instant Timer) لقارئ الشاشة NVDA

تُتيح إضافة المؤقت الفوري (Instant Timer) لمستخدمي قارئ الشاشة NVDA ضبط مؤقتات العد التنازلي وساعة الإيقاف، عبر طبقة أوامر سريعة (`NVDA+E`) تُغلق تلقائياً فور تنفيذ الأمر صيانةً للوحة المفاتيح من الحبس. وتشتمل الإضافة على خمسة مؤقتات مستقلة، ومؤقت سريع عابر، وساعة إيقاف، مع تنبيهات صوتية ونطقية مخصصة.

## الخصائص

- **طبقة الأوامر**: تُفتح بضغط `NVDA+E`؛ يؤدي ضغط أي مفتاح داخلها إلى تنفيذ أمره وإغلاق الطبقة فورياً. ضغط أي مفتاح غير معرف يُطلق نغمة خطأ منخفضة ويُغلق الطبقة دون إبطاء.
- **خمسة مؤقتات مسبقة الضبط**: مددها الافتراضية (5، 10، 15، 25، 60 دقيقة)، مع إمكانية تعديل مدة كل مؤقت وتسميته في أي وقت.
- **المؤقت السريع (`Q`)**: مؤقت تنازلي عابر يعمل في الذاكرة الحية لمرة واحدة دون المساس بالمؤقتات الخمسة الدائمة؛ ضغط مفتاح `Q` حال توقفه يفتح حوار الضبط موجهاً إلى حقل الدقائق مباشرة، ويبدأ بالضغط على مفتاح الإدخال Enter.
- **ساعة الإيقاف (`S`)**: قياس الوقت المنقضي تصاعدياً في الذاكرة الحية.
- **تنبيهات صوتية ونطقية**: رنين مخصص ينطلق فور انتهاء المؤقت مع نطق اسمه، ونغمة تحذيرية اختيارية تسبق الانتهاء بمهلة يحددها المستخدم بالثواني.
- **استئناف الجلسات**: حفظ المؤقتات النشطة عبر إعادة تشغيل NVDA وفق التفضيل المختار (استئناف، تصفير، أو إبقاء معلقاً).
- **لوحة إعدادات متكاملة**: لوحة تفضيلات في قائمة NVDA (`قائمة NVDA > تفضيلات > إعدادات > المؤقت الفوري`).

## مسرد الأوامر

تُفتح الطبقة بضغط **`NVDA+E`**. تصدر نغمة هادئة تؤكد الدخول (إن كانت مفعلة في الإعدادات)، ثم يُضغط أحد المفاتيح الآتية:

| المفتاح | الإجراء |
| :--- | :--- |
| من `1` إلى `5` | الاستعلام عن الوقت المتبقي، أو بدء العد إن كان متوقفاً |
| `Shift` + من `1` إلى `5` | تصفير المؤقت وإعادته إلى مدته الأصلية |
| `Control` + من `1` إلى `5` | فتح حوار تعيين المدة والتسمية |
| `Alt` + من `1` إلى `5` | تعليق المؤقت أو استئنافه |
| `Q` | الاستعلام عن المؤقت السريع (أو فتح حوار الضبط وبدؤه إن كان متوقفاً) |
| `Shift` + `Q` | تصفير المؤقت السريع وإسكات رنينه |
| `Control` + `Q` | فتح حوار ضبط المؤقت السريع وبدؤه فورياً |
| `Alt` + `Q` | تعليق المؤقت السريع أو استئنافه |
| `S` | الاستعلام عن وقت ساعة الإيقاف، أو بدء تشغيلها |
| `Shift` + `S` | تصفير ساعة الإيقاف وإيقافها عند الصفر |
| `Control` + `S` | إعادة بدء ساعة الإيقاف فوراً من الصفر |
| `Alt` + `S` | تعليق ساعة الإيقاف أو استئنافها |
| `مسافة (Space)` | إسكات صوت الرنين |
| `A` | إعلان حالة جميع المؤقتات |
| `H` | فتح نافذة المساعدة في نمط التصفح |
| `هروب (Escape)` | الخروج من طبقة الأوامر |

ضغط أي مفتاح غير معرف داخل الطبقة يُطلق نغمة خطأ ويُعيد لوحة المفاتيح إلى حالتها الطبيعية فوراً.

## الإعدادات

لتخصيص الخيارات، انتقل إلى: **قائمة NVDA > تفضيلات > إعدادات > المؤقت الفوري**:

1. **نمط التنبيه عند انتهاء المؤقت**: صوت فقط، نطق فقط، أو صوت ونطق معاً.
2. **مستوى الإسهاب النطقي**: مبتدئ (إرشادات تفصيلية) أو متقدم (أرقام مقتضبة).
3. **إصدار نغمة صوتية عند الدخول في طبقة الأوامر**: تفعيل نغمة الدخول عند ضغط `NVDA+E` أو تعطيلها.
4. **إصدار نغمة تحذيرية قبل انتهاء الوقت**: تفعيل صفير تحذيري يسبق بلوغ الصفر.
5. **وقت النغمة التحذيرية المسبقة بالثواني**: تحديد مهلة التنبيه بالثواني (من 1 إلى 300 ثانية، افتراضياً: 10 ثوانٍ).
6. **السلوك عند إعادة تشغيل NVDA**: استئناف المؤقتات النشطة، تصفيرها جميعاً، أو إبقاؤها موقوفة مؤقتاً.
7. **استعادة المدد الأصلية لكافة المؤقتات**: إعادة تعيين المؤقتات الخمسة إلى مدد المصنع (5، 10، 15، 25، 60 دقيقة) وحذف التسميات المخصصة.
